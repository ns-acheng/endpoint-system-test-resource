How the December number (37 cases) is calculated

  1. Capacity per month comes from what was really delivered. Every finished case was given an effort estimate in engineer-days (same 1-5 rubric), and the days are added up by the month the case first landed on GRS main:
    MonthCases deliveredEngineer-days
    Sep 2026635.0
    Oct 20261539.0
    Nov 2026 (first 17 days: 93.5 days × 30/17)46165.0
    Low = the smallest of the three (35.0), Base = their average (79.7 engineer-days per month), High = the largest (165.0).
  2. Order of work. The 74 merged cases are sorted easiest first (score 5, then 4, then 3, then 2), and inside a score by fewest days.
  3. Fill December. Add the days of the cases in that order until the total would pass 79.7. That gives 33 merged cases = 37 plan cases (1 of score 5, 14 of score 4, 18 of score 3), using 79.5 engineer-days. The next case, MW1-022 (3.0 days), would make it 82.5, which is over 79.7, so it starts in January.
  4. January, February and March repeat the same step with the same capacity. A plan case counts as done when the merged case that contains it is done; that is why 33 merged cases are 37 plan cases.
