Independent audit

A second agent re-derives each behaviour fact from the raw log with its own regex.

Study gate

A task cannot leave study until the checklist has no FAIL line.

facts become usable
TagMeaningMay a pass criterion rest on it?
observedSeen in a log line, a file or an API answer on a real clientYes
sampleSeen n times; n must be 5 or more for a timing or count claimOnly with n ≥ 5
inferred / docA document claim or a reading, not seen on a clientNo: it becomes a needs-POC row
